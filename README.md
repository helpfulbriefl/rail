# Rail — умная рельса для Windows из трея

Лёгкая портативная док‑панель: ярлыки → живые блоки процессов со светофором, счётчиком окон и мини‑диспетчером задач.

> ## Статус
> **Проект в активной разработке — НЕ «release‑ready» и НЕ все заявленные в старых документах исправления подтверждены.**
> Реализован стек Tauri 2 + React (без Electron). Известные дефекты Owner'а (внешний drop, кнопка «+», флуктуация системных метрик, нестабильность hover) **задокументированы как открытые** в `.bro/exchange/W1-RECON/recon/09_project_questions.md`; доставляемый бинарник устарел относительно исходников этого репозитория (см. recon 09, Q-009). Не используйте как готовый продукт.

## Как пользоваться

| Действие | Что происходит |
|---|---|
| ЛКМ по иконке в трее | Панель плавно выезжает (повторный клик — прячет) |
| ПКМ по иконке в трее | Меню: показать, закрепить, тема, положение, автозапуск, настройки, выход |
| Подвести мышь к краю экрана | Панель выезжает сама (можно выключить) |
| Тащить файл / ярлык к краю | Панель выезжает, иконки раздвигаются, отпускаешь — ярлык встаёт на место |
| Перетащить иконку на панели | Перестановка, соседи сдвигаются (как на Android) |
| Навести на иконку | Увеличение с «расталкиванием» соседей (dock‑эффект) |
| Держать курсор (настройка `hoverDelayMs`, по умолчанию 0.9 с, максимум 3 с) | Карточка: последний запуск, число запусков, путь · у запущенного — CPU / RAM / диск / аптайм |
| Клик | Запуск → иконка превращается в блок с лампой. По запущенному: фокус → свернуть → перебор окон |
| Shift + клик / колесо | Ещё одна копия (окно) |
| ПКМ по иконке | Новое окно · закрыть все окна · расположение файла · убрать с панели |
| Мышь ушла | Через `hideDelayMs` (по умолчанию 1.2 с) панель уезжает (кнопка 📌 — закрепить) |

### Светофор
🟢 работает · 🟠 нагрузка / запуск · 🔴 не отвечает · 🔵 вспышка — активный диск · 🟣 вспышка — резкий рост памяти.
1 окно — «дышащая» лампочка; 2+ окон — стопка карточек и цифра.

## Сборка (проверенные команды)

Требуется **Rust/Cargo**, **Node ≥ 20** и **WebView2** (встроен в Windows 10/11).

```bash
npm ci                                   # зависимости (frontend + @tauri-apps/cli)
npx tauri build --no-bundle              # → src-tauri/target/release/rail.exe
```

Отладочный цикл: `npm run dev` (vite) + `npm run tauri dev`.

ЦИ‑pipeline (`.github/workflows/build.yml`) в этой публикации **не включён** из‑за ограничения scope токена, которым делался публичный снапшот (Q‑005); файл остаётся локальным и добавится, когда появится токен со scope `workflow` или классический PAT.

## Проверки (QA)

```bash
npm run typecheck     # tsc -p .
npm run lint:css      # stylelint "src/**/*.css"
npm run build         # tsc && vite build
npm run qa            # всё выше + node qa/visual.mjs + node qa/storyboard.mjs
```

`qa/` — визуальные/сториборд‑проверки webview‑окон × 4 темы (Playwright + mock‑бэкенд). **Нативные Win32‑пути (`win.rs`/`tracker.rs`) автоматическими тестами не покрыты.**

## Известные дефекты (открытые, без ремонта в этом волне)
- **B‑001** внешний drag/drop: механизм — `SetWindowRgn`‑клиппинг в `win.rs:308`; точный воспроизводящий вариант не установлен (Q‑008).
- **B‑003** кнопка «+»: путь в исходниках корректен (`main.rs:419` callback‑`pick_files`); на старом бинарнике диалог не открывается (Q‑009).
- **B‑004** системные метрики в футере — это **системный** счётчик (`tracker.rs:102` EMA α=0.25), он следует за OS, а не за процесс Rail.
- Полная таблица и ответы — в `.bro/exchange/W1-RECON/recon/09_project_questions.md`.
