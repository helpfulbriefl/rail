# Rail — умная рельса для Windows из трея

Лёгкая портативная док‑панель: ярлыки → живые блоки процессов со светофором, счётчиком окон и мини‑диспетчером задач.

**Скачал → запустил.** Один `rail.exe` (~4 МБ), без установки. Нужен только WebView2 (уже есть в Windows 10/11).

Текущая версия: **1.0.0**. Настройки хранятся в портативном `rail.config.json` рядом с `rail.exe`
(если рядом писать нельзя — в `%APPDATA%\Rail`). Конфиг меняется атомарно (временный файл →
rename), поэтому сбой записи не может уничтожить рабочую конфигурацию; при ошибке сохранения
на панели появляется жёлтый значок ⚠.

## Темы

Шесть тем: **Классика · светлая**, **Классика · тёмная**, **Фарфор**, **Аврора**, **Стекло** (по умолчанию для новой конфигурации), **Студия**.
Выбор — в настройках или в меню трея; сохранённая тема сохраняется.

## Мини‑диспетчер

Наведи курсор на блок CPU/RAM в футере панели (задержка — как у автоскрытия, по умолчанию 1.2 с)
или кликни по нему — открывается системный монитор:

- топ приложений по CPU или по RAM (вкладки, RAM — по умолчанию), упорядоченно по **полному пути** exe;
- в каждой строке сразу обе метрики: CPU % и RAM (Б/МБ/ГБ), плюс счётчик процессов и окон;
- в футере монитора — системные итоги и компактные графики истории CPU и RAM;
- кнопка «×» отправляет окнам только `WM_CLOSE` — приложение может показать диалог несохранённых данных;
- результат действия честный: `×N` (закрыто N окон), «нельзя» (защищённый процесс), «нет» (нет валидных окон).

### Определения метрик

- **CPU %** — сумма CPU всех процессов приложения, нормированная на полное число логических ядер (0–100 % системы).
- **RAM** — сумма памяти (working set) всех процессов приложения; приложение = процесс(ы) с одинаковым полным путём exe.
- Опрос: ~1 с при открытом мониторе, ~1.4 с при видимой панели, полностью останавливается, когда скрыто и панель, и монитор.
- Сглаживание EMA (α = 0.25) с мёртвыми зонами: 0.6 п.п. системный CPU, 0.3 п.п. на приложение, 24 МБ / 4 МБ по памяти.
- Каждый кадр несёт метку времени; если данным в списке больше ~6 с, монитор честно помечает их устаревшими.

### Ограничения закрытия

- Только `WM_CLOSE`: никаких `TerminateProcess`, повышения прав и обхода диалогов.
- Цель закрытия привязана к снимку: полный путь + PID + время старта процесса + владение окном; устаревшая цель — отказ.
- Защищённые процессы (системные каталоги, svchost, оболочка, сам Rail) определяются по полному пути и политике, а не по подстроке имени.
- Пока курсор на строке, состав и порядок строк заморожены — «×» не уезжает на другое приложение при переоценке рейтинга.

## Как пользоваться

| Действие | Что происходит |
|---|---|
| ЛКМ по иконке в трее | Панель плавно выезжает (повторный клик — прячет) |
| ПКМ по иконке в трее | Меню: показать, скрыть, закрепить, тема, положение, автозапуск, настройки, выход |
| Подвести мышь к краю экрана | Панель выезжает сама (можно выключить) |
| Тащить файл / ярлык к краю | Панель выезжает, иконки раздвигаются, отпускаешь — ярлык встаёт на место (дубликаты не добавляются) |
| Перетащить иконку на панели | Перестановка, соседи сдвигаются (как на Android) |
| Навести на иконку | Увеличение с «расталкиванием» соседей (dock‑эффект) |
| Держать курсор 5 с | Карточка: последний запуск, число запусков, путь · у запущенного — CPU / RAM / диск / аптайм |
| Клик | Запуск → иконка превращается в блок с лампой. По запущенному: фокус → свернуть → перебор окон |
| Shift + клик / колесо | Ещё одна копия (окно) |
| ПКМ по иконке | Новое окно · закрыть все окна · расположение файла · убрать с панели |
| Мышь ушла | Через настроенную задержку (по умолчанию 1.2 с) панель уезжает (кнопка 📌 — закрепить) |
| Навести или кликнуть на CPU/RAM в футере | Мини‑диспетчер: топ по CPU или RAM, обе метрики в строке, безопасное закрытие |
| Escape | Сначала закрывает мини‑диспетчер, затем прячет панель |

### Светофор

🟢 работает · 🟠 нагрузка / запуск · 🔴 не отвечает · 🔵 вспышка — активный диск · 🟣 вспышка — резкий рост памяти.
1 окно — «дышащая» лампочка; 2+ окон — стопка карточек и цифра.

## Сборка (проверенные команды)

```bash
npm ci
npm run build                              # tsc + vite → dist/
cargo build --manifest-path src-tauri/Cargo.toml --release --locked   # → src-tauri/target/release/rail.exe
npx tauri build --no-bundle                # полный EXE со всеми ассетами
```

## Проверки (QA)

```bash
npm run qa        # типы TS + stylelint + сборка + 38 визуальных сцен × 6 тем + раскадровки (PASS/FAIL)
cargo test --manifest-path src-tauri/Cargo.toml --locked   # 30 юнит-тестов Rust (конфиг, атомарная запись, нормализация путей, рейтинги, геометрия)
```
