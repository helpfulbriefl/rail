## Как перевести проект
Строка из TRIGGERS.md «Проект уже есть». Аналитик увидит BRO-MAP.md и BRO-LOG.md, выберет сценарий E2 и первой волной (W-MIGRATE) перенесёт файлы в `.bro/` через `git mv`, сохранив историю и все номера D-, G-, L-.
