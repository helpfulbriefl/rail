# Карточка проекта
Заполни, что знаешь, и вставь в первый чат аналитика. Пустое аналитик возьмёт по умолчанию или спросит в брифе.

```text
Проект:
Что это (1–2 строки):
Путь на ПК:                  C:\proj\<имя>
ОС / оболочка:               Windows 11 / PowerShell
Стек:                        выберет аналитик (по умолчанию Bro-26, modules/UI-STACK.md)
GitHub-репозиторий:          нет / <URL>
Второе зеркало (mirror):     нет / <URL>
Папка-зеркало на ПК:         %LOCALAPPDATA%\BRO-MIRROR\<проект>\
Модель кодера (Zoo Code):
Что уже сделано:
Что болит:
Чужое — не трогать:
Где лежат секреты:           только пути, без значений
Режим:                       NEW / JOIN / LOCAL
```
